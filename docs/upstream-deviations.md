## tooling

- `packages/pyright/scripts/parity-check.mjs`: fork-local parity harness. Runs the reference CLI (`dist-cli/pyright.js`), the `bun --compile` binary, and the scriptc-native binary over the same sample project, normalizes volatile output (paths, version strings, timing), and diffs `--version` / default stdout / `--outputjson` + exit codes. Exit 0 = parity or `PENDING` (binary absent), 1 = divergence. Binaries parameterized via `PARITY_REF` / `PARITY_BUN` / `PARITY_NATIVE` env (`skip` to omit).
- `packages/pyright/scripts/parity-fixtures/`: normalized baseline outputs (`reference.*`, `bun.*`) plus `sample/` — a copy of the `/tmp/parity2` project (strict config, `ok.py`, `err.py` with 2 errors, stdlib imports) so the sample survives `/tmp` wipes. See its README for the recreate commands.
- `packages/pyright/scripts/probe.mjs` + `packages/pyright/scripts/probes/`: probe-first fence harness. Each probe is a <30-line program compiled through `node ~/repos/scriptc/packages/cli/dist/main.js build <file> --emit obj` in ~1.5s; `--run` diffs stdout+exit vs Node via the `SCRIPTC` binary, `// probe-expect: diverge` marks expected native divergence (XFAIL/XPASS). Six probes cover the known fence classes (uri-template, class-capture, map-union, fs-seam, stdlib-surface, nls-lazy — the localize.ts lazy-read seam: fs.readFileSync + JSON.parse + miss-then-hit candidate loop; `node==native` PASS under scriptc 0.3.6).
- `packages/pyright-internal/src/tests/scriptcUriSeam.test.ts`: jest seam-isolation test — instruments `toString` on all Uri classes, runs a real `typeAnalyzeSampleFiles` analysis, and fails on any implicit-coercion site not in the pinned 5-site BASELINE. Catches new Uri→string leaks in ~1.5s under Node, no scriptc build needed.
- `packages/pyright-internal/src/checkMain.ts` + `packages/pyright/src/checkMain.ts` + `bundle:check:flat`: reduced-scope single-threaded typecheck entry (no verifytypes/createstub/threads/watch). Measured only ~1.5% smaller than the full flat bundle — kept as a convenience entry, not an emit win. See `docs/iteration-guide.md` for the full measured rebuild curve and workflow.
